# Whop клипинг — трекер кампаний и выплат

Одностраничное приложение для клиперов, работающих с кампаниями Whop Content Rewards.
Без сервера и установки: откройте `index.html` в браузере.

## Возможности
- **Кампании**: ставка за 1000 просмотров (CPM), минимум просмотров, лимит выплаты на клип, бюджет, платформы, требования.
- **Клипы**: платформа, ссылка, дата, просмотры, статус (на проверке / одобрен / отклонён). Просмотры обновляются прямо в таблице.
- **Выплаты**: учёт полученных денег по кампаниям.
- **Обзор**: просмотры, заработано, ожидает проверки, получено, к получению, фактический CPM, освоение бюджета, статистика по платформам.
- **Данные**: экспорт/импорт JSON, экспорт клипов в CSV (для Excel), демо-данные.

## Расчёт
Заработок клипа = просмотры ÷ 1000 × CPM. Ниже минимума просмотров — $0; при заданном лимите сумма ограничивается им; отклонённые клипы не считаются.
«К получению» = заработок одобренных клипов − полученные выплаты.

Данные хранятся в `localStorage` браузера — делайте резервный экспорт JSON.
